01

Ephemeral Nonce

16-byte cryptographically random nonce generated per page load via crypto.getRandomValues(). Non-replayable across sessions.

02

Verifiable Delay Function

Sequential modular squaring over M31. Every attacker pays the same CPU cost. No parallelism. No GPU bypass.

03

Key Derivation

VDF output hashed via SHA-256 (Web Crypto API) to produce a 32-byte symmetric key. Key is unreachable without completing the VDF.

04

XOR Stream Cipher

Payload encrypted client-side. Decryption requires re-running the exact VDF chain. Proof-of-compute is mandatory.

05

Pipeline Hook

On unlock, onSuccessPipeline() fires — giving integrators a hook for redirect, token issuance, or any downstream logic.

06

WASM Edition

113-byte hand-assembled WebAssembly module using native i64.mul + i64.rem_u. 5× faster. JS fallback included.
